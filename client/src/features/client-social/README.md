## Client Social Feature

This folder is reserved for the legacy client social workflow currently defined in `appscript/client-index.html`.

Planned React scope:

- Social task listing
- Platform and status filters
- Social details modal
- Approve / request changes actions
- Social history rendering
- Client remark submission

Legacy source of truth:

- `#social-view`
- `#social-platform-filter`
- `#social-status-filter`
- `#client-social-table`
- social details and action SweetAlert flows
