## To-Do Feature

This folder is reserved for the employee To-Do workspace currently embedded inside the legacy employee portal.

Planned React scope:

- To-Do list surface
- To-Do CRUD actions
- Bulk add
- Toggle complete state
- Filters and employee-scoped behavior

Legacy backend functions:

- `getTodos`
- `addTodo`
- `toggleTodoStatus`
- `editTodoItem`
- `deleteTodoItem`
- `addBulkTodos`
