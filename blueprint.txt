1. Executive Summary

Current system is a Google Apps Script + Google Sheets based ERP MVP with three major portals: WorkTrack
Employee/Admin Portal, Client Portal, and Master Analytics Dashboard. It already includes users, hierarchy, attendance,
leave/intimation, tickets, expenses, FMS, To-Do, client tickets, payment restriction, invoices, reports, WhatsApp notifications,
and trigger-based reminders.

Developer objective: convert this MVP into a stable ERP product with central authentication, role based access control,
normalized database, audit logs, clean APIs, reusable UI modules, and reliable reporting. The sections below describe every
current module, required screens, backend services, database tables, workflows, validation rules, and missing improvements.

17. Ticket is created by employee/admin/client/batch.
18. System generates stable unique ticket ID; row number must not be primary ID.
19. Ticket is assigned to employee or queue.
20. Assignee receives notification with TAT, priority, client, and description.

22. Assignee may pause/resume; system stores each session.
23. If input from client is required, assignee sends to client with clear question/attachment.
24. Client responds from Client Portal; status becomes Client Responded.
25. Assignee completes work and submits for approval.
26. Approver reviews output, duration, remarks, and either closes or sends rework.
27. Closed ticket appears in client report and ERP dashboard.

25. Security and Compliance Requirements

 Never store or send plain passwords. Replace default password flow with one-time password setup link.
 All access checks must happen server-side, not only by hiding UI buttons.
 Every create/update/delete/approval/login should write audit_logs.
 Files should not be public by default. Use signed URLs or permissioned Drive links.
 Client portal must enforce tenant isolation by client_id on every query.
 Use input validation and sanitization for messages, remarks, descriptions, uploaded file names, and filters.
 Use rate limits for login and OTP actions.
 Use backups and database migration scripts. Do not edit production schema manually.
 Use environment variables/secrets for spreadsheet IDs, WhatsApp tokens, email settings, and storage credentials.
 Create admin settings for hardcoded values like grace days, restricted roles, CRM TAT overrides, reminder timings.
